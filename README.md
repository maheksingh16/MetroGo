# MetroGo

A full-stack metro ticket booking and management system.

## Planned Features

- User registration and login
- Source and destination selection
- Metro route calculation
- Fare calculation
- Ticket booking
- QR-based digital ticket
- Booking history
- Admin dashboard
- Station and route management

## Planned Technology

Frontend: React.js
Backend: Java + Spring Boot
Database: PostgreSQL
Authentication: JWT
Version Control: Git + GitHub
